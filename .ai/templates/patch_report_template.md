# Patch Report Template

## Purpose
Provide a reusable format for summarizing a patch, fix, or change set.

## Required Fields
- [CHANGE]
- [REASON]
- [RISK]
- [VALIDATION]
- [ROLLBACK]

## Report Sections
- Summary
- Scope
- Impact
- Validation
- Open Questions

## Expected Output
A concise report that helps reviewers understand the intent, scope, and evidence behind a patch.
