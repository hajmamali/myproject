# Code Review Template

## Purpose
Provide a reusable structure for reviewing implementation quality and architectural fit.

## Required Fields
- [CHANGE]
- [REASON]
- [RISK]
- [VALIDATION]
- [ROLLBACK]

## Review Questions
- Is the change clear and minimal?
- Does it preserve or improve maintainability?
- Are tests, documentation, and risk notes sufficient?

## Expected Output
A review that focuses on correctness, clarity, maintainability, and architectural alignment.
