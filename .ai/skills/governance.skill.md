# Governance Skill

## Purpose
Ensure that work is aligned with repository policy, review discipline, and architectural accountability.

## When To Apply
Use for changes that affect policy, review expectations, process, or cross-cutting standards.

## Required Knowledge
- Constitution
- Decision framework
- Engineering standards

## Workflow
1. Identify the governance concern.
2. Compare it to repository policy.
3. Determine whether exception handling is required.
4. Document the decision and its impact.

## Rules
- Keep governance enforceable and observable.
- Prefer transparent decisions over informal exceptions.

## Forbidden Actions
- Bypassing review requirements.
- Introducing undocumented policy exceptions.

## Quality Gate
A governance decision is acceptable only if it is explicit, justified, and consistent with the constitution.
