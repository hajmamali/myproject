# Static Analysis Skill

## Purpose
Support disciplined inspection of repository structure and implementation characteristics without relying on superficial heuristics.

## When To Apply
Use when analyzing code structure, dependency shapes, or architectural consistency.

## Required Knowledge
- Repository model
- Graph and dependency concepts
- Architecture and testing guidance

## Workflow
1. Gather the relevant source context.
2. Understand the surrounding architecture and boundaries.
3. Identify patterns of duplication, drift, or incoherence.
4. Report findings with evidence and recommendations.

## Rules
- Treat static analysis as a guide to architecture rather than a conclusion.
- Validate findings against the shared model.

## Forbidden Actions
- Drawing conclusions from isolated observations.
- Replacing architectural reasoning with pattern matching alone.

## Quality Gate
Static analysis is useful only when it produces actionable and evidence-based insight.
