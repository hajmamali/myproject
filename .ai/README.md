# AI Governance and Agent Operating System

## Purpose
This directory defines the repository’s internal governance framework for human contributors and AI agents. It exists to preserve architectural quality, reduce duplication, and guide disciplined decision-making.

## Scope
Use this directory as the primary reference for architecture, standards, workflow expectations, and review practices.

## Required Reading Order
1. Constitution
2. Architecture
3. Engineering Standards
4. Agent Workflow
5. Decision Framework
6. Canonicalization Guidance

## Key Documents
- Constitution: defines the non-negotiable principles and obligations.
- Architecture: defines the architectural philosophy and model-driven approach.
- Engineering Standards: defines quality expectations for implementation and documentation.
- Agent Workflow: defines the mandatory operating sequence for agents.
- Decision Framework: defines how trade-offs and risks should be evaluated.
- Canonicalization Guidance: defines how canonical implementations should be selected.

## Agent Obligations
Before making architectural or structural changes, agents should:
- read the relevant governance documents,
- inspect the shared architecture model,
- evaluate the impact on maintainability and correctness,
- and document the rationale for the decision.

## Expected Behavior
Contributors should treat this directory as the repository’s operating manual for disciplined engineering and governance.
