# Correlation ID Integrity Test Suite

**Quick Reference Guide**

## What This Test Suite Does

Validates that **Correlation IDs** are correctly:
1. Generated by the Kernel
2. Propagated through all components
3. Stored in Neo4j nodes and relationships
4. Traceable for complete audit trails
5. Isolated between different executions

## Test File

```
tests/governance/test_correlation_id_integrity_e2e.py
```

## Quick Run

```bash
# Run all tests (requires Neo4j)
pytest tests/governance/test_correlation_id_integrity_e2e.py -v

# Run tests without Neo4j (governance layer only)
pytest tests/governance/test_correlation_id_integrity_e2e.py -v -k "Creation or Evidence or missing_governance"

# Run specific test
pytest tests/governance/test_correlation_id_integrity_e2e.py::TestCorrelationIDCreation -v
```

## Architectural Guarantees Tested

1. ✅ **Unique ID Generation** - Each execution gets unique correlation ID
2. ✅ **Propagation** - IDs propagate unchanged through pipeline
3. ✅ **Evidence Traceability** - Evidence contains correlation metadata
4. ⏸️ **Node Integrity** - Neo4j nodes contain correlation_id
5. ⏸️ **Relationship Integrity** - Neo4j relationships contain correlation_id
6. ⏸️ **Execution Isolation** - No contamination between executions
7. ✅ **Fail-Closed** - Missing context causes rejection
8. ⏸️ **Audit Trail** - Full traceability from entity to execution

## Key Test Patterns

### Creating Test Execution Context

```python
async with GovernanceContextManager.active_context(
    correlation_id="TEST-CORR-ID-001",
    execution_mode="STRICT",
    actor_id="test-actor",
) as ctx:
    # Perform operations
    assert ctx.correlation_id == "TEST-CORR-ID-001"
```

### Writing to Graph with Correlation ID

```python
with connection.governed_session(
    correlation_id="TEST-CORR-ID-001",
    actor_id="test-actor",
) as session:
    session.write_node(
        label="TestEntity",
        node_data={
            "id": "entity-123",
            "correlation_id": "TEST-CORR-ID-001",
        },
    )
```

### Verifying Graph Correlation ID

```python
with connection._session() as session:
    result = session.run(
        "MATCH (n) WHERE n.correlation_id = $corr_id RETURN count(n)",
        {"corr_id": "TEST-CORR-ID-001"}
    )
    assert result.single()["count"] > 0
```

## Troubleshooting

### Neo4j Not Available

**Symptom:** 10 tests skipped with "Neo4j not available" message

**Solution:** Start Neo4j service:
```bash
docker-compose up -d neo4j
# OR
systemctl start neo4j
```

### Test Data Contamination

**Symptom:** Tests fail due to existing test data

**Solution:** Clean test data manually:
```cypher
MATCH (n) WHERE n.correlation_id STARTS WITH 'TEST-CORR-'
DETACH DELETE n
```

### Governance Context Errors

**Symptom:** `GovernanceViolationError: No active governance context`

**Solution:** Ensure all tests use `GovernanceContextManager.active_context()`:
```python
async with GovernanceContextManager.active_context(...) as ctx:
    # Test code here
```

## Adding New Tests

1. **Choose appropriate test class** based on component being tested
2. **Use test correlation ID prefix:** `TEST-CORR-*`
3. **Mark as P0 critical:** `@pytest.mark.p0_critical`
4. **Use fixtures:** `clean_neo4j_test_data`, `test_actor`
5. **Document guarantee** in test docstring
6. **Clean up test data** in fixture

Example:
```python
@pytest.mark.p0_critical
@pytest.mark.asyncio
async def test_my_new_correlation_feature(
    self, clean_neo4j_test_data, test_actor
):
    """
    Test that [component] correctly [behavior] with correlation_id.
    
    Architectural guarantee: [describe what this test proves]
    """
    test_correlation_id = "TEST-CORR-NEW-FEATURE-001"
    
    # Test implementation
    ...
```
